# BARE DAYS

> 이미지 갤러리 웹사이트 | 웹 디자인·퍼블리싱 / 프론트엔드 포트폴리오

## 프로젝트 소개
높이가 다른 이미지를 자연스럽게 나열하는 Pinterest 스타일 갤러리를 제작했습니다. 사진이 강조되는 카드 배치와 카테고리별 탐색을 중심으로 구성했습니다.

## 사용 기술
HTML · CSS · JavaScript · Isotope

## 주요 작업 내용

### 01. 이미지 카드
사진 20개에 제목과 설명을 넣고 크기가 다른 카드가 모이는 갤러리 레이아웃을 제작했습니다.

### 02. 카테고리 필터
ALL, DESIGN, WEB 버튼을 눌렀을 때 해당 카드만 표시되도록 Isotope 필터와 버튼 이벤트를 연결했습니다.

### 03. 헤더 디자인
블루 그라데이션과 위로 움직이는 별 배경을 적용했습니다.

### 04. 반응형 구성
화면 크기에 따라 카드 열 수와 헤더 배치를 조정했습니다.

## 작업하면서 익힌 내용
Isotope 라이브러리의 정렬·필터 동작과 JavaScript 클릭 이벤트를 함께 사용해 보았습니다. 이미지 높이가 달라질 때도 전체 레이아웃을 일정하게 유지하는 방법을 익혔습니다.

## 프로젝트 정리
사진 중심의 시각적 구성에 실제 필터 동작을 더해 탐색 가능한 갤러리를 완성했습니다.
